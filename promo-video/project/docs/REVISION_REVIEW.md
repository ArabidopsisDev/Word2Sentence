# 审阅与修改记录

## R01

- 反馈原意：视频开头必须说明这是开源软件，圈外观众需要用一两句话理解“开源”。
- 判断：准确。
- 根因：若先展示完整 AI 功能界面，普通观众可能先把它归类为商业订阅软件并退出。
- 最小修改：前两条字幕直接说明“开源软件、自由下载、源码公开、可查看和改进”，再进入学习问题。
- 影响：opening、part 01、summary。
- 验证：首次观看者必须在 6 秒内复述“程序可自由下载且源码公开”。
- 当前状态：resolved；V7 首次观看者在前 8 秒准确复述免费、源码公开与学习痛点。

## R02

- 反馈原意：画面可以使用软件截图、生成图像和动画，使用中文；风格干净，不像商业广告。
- 判断：准确。
- 根因：通用宣传片模板容易加入浮动设备、粒子、增长曲线和口号，偏离个人开源项目气质。
- 最小修改：以中文实机窗口和 `distract` 的单一学习流程为主，辅助图形只解释关系。
- 影响：全片视觉系统、截图计划、封面。
- 验证：视觉审阅统计主构图、商业广告禁用元素和手机尺寸可读性。
- 当前状态：resolved；V7 视觉专项审阅通过。

## R03

- 反馈原意：宣传片要充满软件截图和功能演示，但连续很长的实机录屏同样愚蠢。
- 判断：准确。
- 根因：纯文字会失去软件可信度，连续录屏又无法控制观众阅读焦点。
- 最小修改：完整窗口只定位 1–2 秒，随后把真实 UI 裁成情境、输入框、反馈句、用法卡、错词窗口和设置区域；图形动画只解释这些裁片之间的关系。
- 影响：全部 7 个主构图、截图捕获脚本和场景渲染器。
- 验证：V7 接触表与完整预览确认没有连续原始录屏，界面推进、输入、批改、用法卡和弹窗形成连续操作链。
- 当前状态：resolved。

## R04

- 反馈原意：片长控制在 1 分 20 秒到 2 分钟。
- 判断：准确。
- 最小修改：最终使用 BGM 源文件 97.9407–182.9807 秒，按完整节拍锁定为 85.04 秒。
- 影响：timeline、storyboard、SRT 和音乐 cue 表。
- 验证：时间线验证报告当前为 0 error / 0 warning。
- 当前状态：resolved；正式 MP4 时长 85.04 秒，完整解码与音画 QA 通过。

## R05

- 反馈原意：宣传片不应出现底部字幕和左上章节编号；当前整体像 PPT，质量不合格。
- 判断：准确，旧版作为不可发布版本处理。
- 根因：底部字幕条与 `01 / 05` 章节栏形成讲解视频框架；自动复习使用截图加四条项目符号，数据边界同时拼三张卡，片尾又是中央落地页。
- 修改：关闭内嵌字幕，仅保留可选外部 SRT；删除章节栏和开场目录；自动复习改为真实设置页占主画面、四项证据逐一锚定；数据边界改为同一设置页连续推近本地数据、OpenRouter 和语言控件；片尾缩至约 3 秒并保留真实首页。
- 影响：`config.json`、`render_animation.py`、`scenes.py`、timeline、音频区间、布局与动画 QA。
- 验证：V7 视觉审阅统计底部字幕 0、章节编号 0、卡片墙 0、纯文字页 0、超过 3 秒静止教学页 0；首次观看、文案、技术、视觉几何均 PASS；release gate 为 0 error / 0 warning。
- 当前状态：resolved。
