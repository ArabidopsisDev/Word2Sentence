# 审阅与修改记录

## R01

- 反馈原意：视频开头必须说明这是开源软件，圈外观众需要用一两句话理解“开源”。
- 判断：准确。
- 根因：若先展示完整 AI 功能界面，普通观众可能先把它归类为商业订阅软件并退出。
- 最小修改：前两条字幕直接说明“开源软件、自由下载、源码公开、可查看和改进”，再进入学习问题。
- 影响：opening、part 01、summary。
- 验证：首次观看者必须在 6 秒内复述“程序可自由下载且源码公开”。
- 当前状态：等待低清预览盲审。

## R02

- 反馈原意：画面可以使用软件截图、生成图像和动画，使用中文；风格干净，不像商业广告。
- 判断：准确。
- 根因：通用宣传片模板容易加入浮动设备、粒子、增长曲线和口号，偏离个人开源项目气质。
- 最小修改：以中文实机窗口和 `distract` 的单一学习流程为主，辅助图形只解释关系。
- 影响：全片视觉系统、截图计划、封面。
- 验证：视觉审阅统计主构图、商业广告禁用元素和手机尺寸可读性。
- 当前状态：等待分镜与低清预览。

## R03

- 反馈原意：宣传片要充满软件截图和功能演示，但连续很长的实机录屏同样愚蠢。
- 判断：准确。
- 根因：纯文字会失去软件可信度，连续录屏又无法控制观众阅读焦点。
- 最小修改：完整窗口只定位 1–2 秒，随后把真实 UI 裁成情境、输入框、反馈句、用法卡、错词窗口和设置区域；图形动画只解释这些裁片之间的关系。
- 影响：全部 7 个主构图、截图捕获脚本和场景渲染器。
- 验证：92 秒第一版无声接触表已确认没有连续完整窗口演示；最终版本将重新生成同类报告。
- 当前状态：resolved，等待 BGM 后复测节奏。

## R04

- 反馈原意：片长控制在 1 分 20 秒到 2 分钟。
- 判断：准确。
- 最小修改：补全隐私与冲突复测边界后，暂定时间线为 109 秒；BGM 到位后只在 80–120 秒内按乐句微调。
- 影响：timeline、storyboard、SRT 和音乐 cue 表。
- 验证：时间线验证报告当前为 0 error / 0 warning。
- 当前状态：resolved，精确时长等待 BGM。
