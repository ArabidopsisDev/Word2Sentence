# 观众模型

## 已掌握

- 知道背单词通常会记录单词和释义。
- 知道造句能练习语言，但未必知道怎样得到可靠反馈。
- 会使用普通 Windows 桌面软件。

## 尚未掌握

- “开源”对普通用户意味着什么。
- Word2Sentence 为什么把造句放在词卡之前。
- AI 评分与 FSRS-6 怎样共同决定复习时间。
- OpenRouter API 和本地数据之间的边界。

## 常见误解

- 看到完整 UI 和 AI 功能后，以为这是需要订阅的商业软件。
- 把整句分数直接理解成复习间隔。
- 以为用户仍需点击“好 / 中 / 差”评价自己。
- 以为“本地优先”意味着造句内容从不发送给模型服务。
- 以为软件只支持英语；实际上界面、目标语言和解释语言可分别设置，但当前演示以英语为例。

## 每章进入条件

| 章节 | 进入前已经知道 | 本章不可提前假设 | 首次观看风险 |
