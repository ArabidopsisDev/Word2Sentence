# 风格研究

## 2026-08-28 参考片与发布动画复盘

### 本地参考 `gal.mp4`

- 39 秒、1920×1080、30fps；功能镜头平均约 3 秒，真正稳定阅读约 1.4–2.1 秒。
- 统一白底、黑色粗标题、灰色副标题、轻微倾斜的完整 UI 平面；UI 与标题沿固定方向进入和离开，因此即使内容并列也保持视觉连续。
- 最有效的转场是浅色界面原位翻转为深色界面，因为同一对象没有消失。
- 不可直接继承：前 9 秒连续四张纯文字页；中后段多次大面积白场；每个功能都复用“标题＋倾斜截图”，没有鼠标、输入、滚动、提交或系统响应，所以缺少真实软件可信度。

### 网上产品发布案例

- Raycast 发布内容把 UI 的速度与产品价值绑定，镜头切换落在音乐强拍，文字和界面共同运动；适合借鉴的是“快进慢停”的缓动与明确 punch-in，不是其高商业强度。
- Reely 等演示工作流把真实 App 运行画面放进统一动效框架：点击发生的时刻决定镜头、相机和标题动作，说明实机与发布动画不需要二选一。
- Craft 的教程区明确区分短产品介绍与较长真实工作流；本片采用相同分工：动画负责定位和不可见机制，完整窗口负责证明操作。

### Word2Sentence 的采用规则

1. 开场最多一问一答，不连续翻纯文字页。
2. 动画中的窗口先从画外进入，再放大回正；回正后的完整窗口直接进入实机流程。
3. 中段始终使用同一 1600×1024 WPF 坐标系：词库 → 练习 → 输入 → 批改 → 滚动 → 确认。
4. 焦点框只绑定真实控件，不额外造卡片；鼠标位置在冻结和继续之间保持连续。
5. FSRS 与数据边界属于不可直接拍到的机制，只在真实结果页或设置页上叠加短线、时间线和局部文字。
6. 片尾保留真实首页，只叠加一句主张和仓库地址。

## 稳定风格

- 背景与留白：暖白大留白，墨绿只标记当前动作；不使用大面积霓虹、渐变光晕或玻璃拟态。
- 字幕与阅读速度：中文单行字幕，暂按 4.5–5.5 秒一条、约 5–7 字/秒设计，精确时长等待 BGM。
- 章节与主构图：开场后给一组轻量目录，四章各保留一个主构图并原地演进。
- 代码语义色：只在解释开源和调度证据时短暂展示真实源码；代码不是全片主角。
- 框、线、箭头：1–2px 细线，动态测量文字范围，不让高亮层覆盖文字。
- BGM：只作为节奏背景，不做广告式强拍堆叠；章节边界等待用户 BGM 后对齐。

## 本主题的适配

- 视觉核心对象：同一个单词 `distract` 从词库进入造句、反馈、用法卡和复习队列的全过程。
- 保留的风格：真实问题先出现，软件功能作为解决步骤逐步出现；画面多用实机截图局部重绘和焦点动画。
- 主动拒绝：手机漂浮模型、奖杯、增长曲线、五颗星评价、价格页、订阅徽章、伪 3D 设备、无意义粒子。
- 手机尺寸风险：软件全屏截图必须放大到当前焦点区域；导航栏和大段非当前内容降亮度或裁切。
