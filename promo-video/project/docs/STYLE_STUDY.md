# 风格研究

## 样本与证据

| 样本 | 观察 | 可迁移规则 | 不可复用内容 |
|---|---|---|---|
| 用户本轮要求 | 动画、干净整洁、不要像商业软件广告；开头立即解释开源 | 克制配色、真实界面、项目事实优先于口号 | 商业发布会式倒计时、价格锚点、夸张收益 |
| Word2Sentence 当前 WPF 界面 | 暖白底、墨绿强调、低圆角、信息密度适中 | 沿用 `#F5F4F0 / #2F6048 / #DDE9E1`，把实机界面作为主视觉对象 | 把整个画面做成另一套 SaaS 仪表盘 |
| Arabidopsis 技术动画规范 | 无旁白、单行字幕、稳定主构图中持续发生局部变化 | 4 个连续部分，每 1–2 秒发生一次有意义的局部变化 | 套用旧视频剧情、卡片墙、HUD 和粒子背景 |

## 稳定风格

- 背景与留白：暖白大留白，墨绿只标记当前动作；不使用大面积霓虹、渐变光晕或玻璃拟态。
- 字幕与阅读速度：中文单行字幕，暂按 4.5–5.5 秒一条、约 5–7 字/秒设计，精确时长等待 BGM。
- 章节与主构图：开场后给一组轻量目录，四章各保留一个主构图并原地演进。
- 代码语义色：只在解释开源和调度证据时短暂展示真实源码；代码不是全片主角。
- 框、线、箭头：1–2px 细线，动态测量文字范围，不让高亮层覆盖文字。
- BGM：只作为节奏背景，不做广告式强拍堆叠；章节边界等待用户 BGM 后对齐。

## 本主题的适配

- 视觉核心对象：同一个单词 `distract` 从词库进入造句、反馈、用法卡和复习队列的全过程。
- 保留的风格：真实问题先出现，软件功能作为解决步骤逐步出现；画面多用实机截图局部重绘和焦点动画。
- 主动拒绝：手机漂浮模型、奖杯、增长曲线、五颗星评价、价格页、订阅徽章、伪 3D 设备、无意义粒子。
- 手机尺寸风险：软件全屏截图必须放大到当前焦点区域；导航栏和大段非当前内容降亮度或裁切。
