# 中文文案独立复读

- 审阅者：`agent-promo-copy-review`
- 输入：当时版本的 `project/content/script.md` 与普通用户观众模型。
- 状态：初稿审阅意见已处理；最终 preview hash 绑定审阅仍待 BGM 版预览。

## 实际发现

1. 开场已经明确“开源软件”，但“可以自由下载”容易被理解为已有安装包；改为“程序本身免费使用，源码公开在 GitHub”，让圈外人理解开源，同时不承诺当前不存在的正式安装包。
2. “它想解决的，是……”较绕；改为“它要解决的是，明明背过单词，真正造句时却仍会卡住”。
3. “独立写下一句真正想表达的话”用力过多；改为“自己写下一句想表达的话”。
4. “按表达质量分段”像内部术语；改为“标出各部分的表达质量”。
5. 两种改写的句子主语不明；改为“系统会同时保留两个版本，一个只改错误，一个表达更自然”。
6. “错词”范围不清；改为“其他掌握不好的词”，与产品的用户确认流程一致。
7. “证据交给 FSRS”拟人化；拆为本地映射、FSRS 调度和冲突复测三层。
8. “三种语言”没有指代；明确为界面、学习目标和 AI 解释语言。

## 复读结论

- 开头两句在 8 秒内同时交代软件类别、免费使用、源码公开与参与改进。
- 没有商业广告式效果承诺、订阅对比、效率口号或强制下载 CTA。
- 字幕自动检查为 0 error / 0 warning；所有字幕保持单行。
