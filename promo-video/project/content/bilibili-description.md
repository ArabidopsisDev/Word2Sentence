# 简介

Word2Sentence 是一款免费使用、源码公开的单词学习软件。你可以主动把不会的词加入词库，在具体情境中自己造句，再获得逐段反馈、修改后的句子、更自然的表达和可复习的用法卡。

复习时间由实际作答表现自动安排，不需要自己选择“好 / 中 / 差”。完整词库与学习历史保存在本机；AI 功能可以不启用，启用时会通过 OpenRouter 把当前练习所需文本交给所选模型处理。

项目目前仍处于 prototype 阶段，欢迎试用、反馈和参与改进。
