# 《word2sentence-promo》屏幕文案

- 声音：仅使用用户提供的 BGM，无配音
- 字幕：严格单行；画面承担代码细节，字幕承担阅读主线

## 开源项目开场（00:00–00:09）

- `00:00–00:03` 大家好，Word2Sentence 是一款开源的单词学习软件。
- `00:04–00:09` 程序本身免费使用，源码公开在 GitHub，也欢迎大家改进。

## 从释义到搭配缺口（00:09–00:22）

- `00:10–00:13` 它要解决的是，明明背过单词，真正造句时却仍会卡住。
- `00:13–00:17` 知道 distract 的意思，轮到自己写句子时，却还是想不起常见搭配。
- `00:18–00:22` 只看释义，往往还发现不了词形和搭配的问题。

## 词库到造句的连续流程（00:22–00:35）

- `00:23–00:26` 因此，练习从你加入词库的生词开始。
- `00:26–00:31` 启用 AI 后，它会给出具体情境，但不会提前写出完整答案。
- `00:31–00:35` 你会在这个情境里，自己写下一句想表达的话。

## 反馈结果拆分与留存（00:35–01:02）

- `00:36–00:40` 句子提交以后，系统会先标出各部分的表达质量。
- `00:40–00:44` 绿色表示表达自然，蓝色表示可以优化，红色表示有错误。
- `00:44–00:49` 系统保留两个版本，一个纠正错误，另一个表达更自然。
- `00:49–00:53` 常用搭配会整理成一条条用法卡，同步到首页。
- `00:54–01:00` 句子里其他可能没掌握的词，会先列出，确认后才加入词库。

## 证据进入自动调度（01:02–01:15）

- `01:02–01:06` 系统会根据这次造句的表现，自动安排下一次复习。
- `01:06–01:10` 答得越稳，这个词通常会晚一些再出现。
- `01:10–01:15` 系统自动判断，不需要你自己选择好、中、差。

## 本地数据与外部服务边界（01:15–01:25）

- `01:15–01:18` 完整词库和历史默认保存在本机。
- `01:18–01:21` AI 可以不启用；启用时只发送当前练习所需文本。
- `01:22–01:24` 界面和学习语言可以分别设置，英语只是演示。

## 从一句话开始（01:25–01:34）

- `01:25–01:30` 前往 GitHub 下载 Word2Sentence，从一个生词、一句话开始。
